# Long walks are checked against the game map
- Before a long walk back, the bot now checks the route against the game's own map, so it takes a way that really exists, for example around the crater rim from Hotan to the Karakoram aircraft dock.
- A step that does not work is left out and the route is planned again around it. A route point the character cannot stand on is passed close by, or skipped.
- While it checks, the status line says so and the character waits; a long route can take a few seconds to a minute.
- If the game's map data cannot be loaded, the walk is done unchecked as before, and the log says so.
- This is beta; the Route check lines in the log show what was checked and what was left out.
> Contributed by corevider (#47). Tested in simulation only, not in a live game.
