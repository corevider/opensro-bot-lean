# Immortal stone first when Astral needs it
- When fusing stones (Alchemy page, Stones that help and protect), an Astral charge only works if the weapon has more Immortal charges than Astral ones. The bot now fuses an Immortal stone first when the weapon needs one.
- This happens even if Immortal is not ticked or is not due yet at the current plus, so Immortal stones can be used up in this case.
- If there is no Immortal stone in the bag, the run stops with a clear message and does not try Astral.
- The help text on the Alchemy page and the manual are updated.
> Contributed by corevider (#71). Tested in simulation only, not in a live game. The Immortal-before-Astral rule is inferred from the game's refusal and is not confirmed on the live server.
