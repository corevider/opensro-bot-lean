# Walk back out of walled towns
- With "On death" set to "Revive and walk back" (Settings → Behaviour, default Stop), a character revived in a walled town can now leave and return to the hunt spot instead of stopping with "No walkable route found".
- Walks now use the game's own movement rules, so exits built from bridges, ramps and floors over blocked ground are found.
- Route planning runs in short steps between frames, so the page stays responsive, and a spot that cannot be reached is not retried for 30 seconds.
- Pursuit and detour moves still use the quick direct route, so combat movement behaves as before.
> Contributed by Rebraxin (#43). Tested in simulation, and by the contributor in a live game.
