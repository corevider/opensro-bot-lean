# Attribute stones skip a stat that ran out
- When fusing attribute stones (Alchemy page, Item attributes), a stat with no stone of the item's degree in the bag is now passed over and the next picked stat is fused, instead of the whole run stopping.
- The log says once for each stat that was passed over.
- The run stops only when every picked stat still below its target has no stones left. The message then names all the stones that ran out.
- The help text on the Alchemy page and the manual are updated.
> Contributed by corevider (#70). Tested in simulation only, not in a live game.
